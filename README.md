# CALVEN Trading Website

A responsive single-page website for CALVEN Trading, positioned around Ethiopian green coffee and buyer enquiries.

## WhatsApp quotation form
The quotation form opens WhatsApp to **+251 960 617 997** with a pre-filled enquiry message. The visitor must review and press Send in WhatsApp. The form does not automatically send messages or store enquiries on a server.

## Publish for free with GitHub Pages
1. Create a public GitHub repository named `calven-trading-website`.
2. Upload `index.html` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. When GitHub Pages finishes deploying, copy the published URL and add it to the CALVEN Trading Instagram profile under **Edit profile → Links → Add external link**.

## Before publishing
- Review all copy and imagery.
- Replace the text wordmark with the official CALVEN logo if desired.
- Confirm that any coffee lot specifications, quantities, pricing, samples, and delivery terms are accurate before quoting.
- The photos are illustrative web-hosted images; replace them with properly licensed or owned images as needed.
